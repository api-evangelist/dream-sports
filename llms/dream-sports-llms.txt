# Horizon - Open Source Universe by DreamSports

> Empowering developers worldwide with production-grade, battle-tested tools and frameworks built at scale.

## Overview

Horizon is DreamSports' open source initiative, sharing battle-tested, production-ready tools, libraries, and frameworks that power Dream11's cutting-edge sports technology platform. All projects serve millions of users at scale and are designed for real-world, high-traffic scenarios.

**Website:** https://dreamhorizon.org
**GitHub:** https://github.com/dream-horizon-org
**Organization:** DreamSports

## Mission & Vision

Empower developers worldwide by open-sourcing enterprise-grade solutions that solve real-world challenges in:
- Mobile application development (React Native, iOS, Android)
- Backend systems and microservices architecture
- Observability, monitoring, and distributed tracing
- Test automation and quality assurance
- Infrastructure management and DevOps
- Cloud cost optimization and management

We accelerate innovation, foster collaborative learning, and build a global ecosystem where developers create better products together.

## 🔍 For Developers Searching For Solutions

### Mobile Development Solutions

**Looking for React Native performance optimization?**
- **Marco**: Performance tracking library for React Native apps. Zero-config setup, lightweight, detects bottlenecks, optimizes user experience with beautiful visualization dashboards.
- **DeFrost**: Debugger specifically for frozen frames in React Native applications. Debug and eliminate UI jank.
- **FastImage**: High-performance image component for React Native with advanced caching, priority loading, placeholder support, and automatic memory management. Significantly faster than default Image component.
- **RN Benchmarking**: Comprehensive benchmarking toolkit to measure React Native app performance, compare across versions, identify optimization opportunities.
- **React Native Impression Tracker**: Track user impressions and visibility analytics in React Native apps.

**Need mobile deployment and updates?**
- **Delivr**: Over-the-air (OTA) update platform for mobile apps. Instant updates, confident rollbacks, progressive feature deployment. Supports React Native, iOS, Android with zero-downtime deployments.
- **Code Push Server**: Standalone CodePush server from App Center for self-hosted OTA updates.

**Server-Driven UI and Dynamic Components:**
- **Flash Client**: Server-Driven UI SDK for building dynamic mobile experiences without app updates.
- **React Native Remote UI**: Remote component system for React Native, enabling dynamic UI rendering.

**Communication & Real-time:**
- **React Native MQTT**: High-performance MQTT library for React Native with reliable message delivery, automatic reconnection, and offline queuing.

**UI Components & Navigation:**
- **React Native WebView**: Cross-platform WebView component for React Native applications.
- **React Navigation Benchmark**: Performance benchmarking for React Native navigation solutions.
- **RN Tabs Benchmarks**: Compare Native Bottom Tabs vs JavaScript Bottom Tabs performance.
- **GorhomBottomSheetBenchmark**: Performance analysis of bottom sheet implementations.
- **RN Webview Benchmark**: Benchmarking tool for WebView performance in React Native.

### Backend & Microservices

**Building scalable backend systems?**
- **Message Kit**: Lightweight Java library for working with message queues. Currently supports Amazon SQS, expanding to additional providers.
- **Kafka Consumer Library**: Robust Kafka consumer implementation for event-driven architectures.
- **Odin Components**: Modular component registry for building scalable applications. Simplifies dependency management, promotes code reusability.
- **Guardian**: Backend security, authentication, and authorization solution. Supports SSO, federation, and AI/agent authentication.
- **Shard Wizard**: Database sharding and data partitioning utilities for distributed systems.

**gRPC & API Development:**
- **Vertx gRPC Extension**: Set of abstractions making it easier to create and maintain gRPC services in Vert.x ecosystem.

**Database & Data Management:**
- **Vertx DynamoDB Client**: Reactive DynamoDB client library built with RxJava, designed for seamless Vert.x ecosystem integration.
- **DataGen**: Generate coherent, synthetic data at scale for testing and development. Enforces complex business rules.

**Machine Learning Integration:**
- **ONNX Runtime**: Cross-platform, high-performance ML inferencing and training accelerator. Run machine learning models efficiently in production.

### Observability & Monitoring

**Need application monitoring and performance tracking?**
- **Pulse**: Real-time monitoring and observability platform for microservices. Track performance metrics, distributed traces, and logs in unified dashboard. Handles millions of events per second.
- **Marco**: React Native performance tracking with visualization dashboards.
- **LogWise**: Unified log visibility that is 4x more cost-efficient and deeply integrated into the developer workflow. Simplifies multi-cloud troubleshooting.
- **Livelogs**: Real-time log aggregation and monitoring solution.

### Testing & QA

**Managing test automation and quality assurance?**
- **Checkmate**: Comprehensive test case management application for modern development teams. Organize test suites, track execution results, generate detailed reports. Seamlessly integrates with CI/CD pipelines.
  - Test case organization and management
  - E2E testing workflows
  - Unit testing integration
  - Test reporting and analytics
  - Test validation and verification
  - QA team collaboration

**React Testing:**
- **Testing React19**: Exploration and testing of React 19 features and capabilities.

### Infrastructure & DevOps

**Managing infrastructure and deployments?**
- **Odin**: Developer platform which enables engineers to define software once and then deploy it anywhere, any number of times. Moves software operations from engineers to machines.
- **Delivr**: OTA deployment platform with progressive rollout capabilities.
- **DeFrost**: Debugging infrastructure for mobile applications.
- **Dota**: DevOps tooling and automation solution.
- **Code Push Server**: Self-hosted code push server for mobile app updates.

### AI & Growth

- **Darwin**: AI development platform to build, train, deploy and scale ML models seamlessly. Abstracts infrastructure complexity.
- **Pulse**: Product growth platform for digital experience analytics. Understand user interactions in real time.
- **Ascend**: Experiment platform for controlled product experiments end-to-end.
- **Flagship**: Feature flag platform for controlled feature delivery, gradual rollouts, and instant rollbacks.
